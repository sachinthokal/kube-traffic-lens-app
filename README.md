# 🚀 Kube Traffic Lens App

A simple Python Flask application designed to demonstrate Kubernetes Deployment Strategies (Rolling Update, Recreate) and Advanced Traffic Management / Splitting using Istio Service Mesh (Canary Deployments).

## 🌟 Features
- **Dynamic Version Badge:** Automatically displays `v1` (Blue) or `v2` (Green) based on environment configuration.
- **Pod Hostname Tracking:** Shows the exact Kubernetes pod handling the request.
- **Traffic Splitting Ready:** Perfect for testing 90-10% traffic routing or header-based routing via Istio.

## 🛠️ Tech Stack
- Python / Flask
- Tailwind CSS
- Docker
- Kubernetes & Istio Service Mesh# kube-traffic-lens-app
